# AMOUR — полноценный MVP

## Что добавлено
- настоящие короткие ссылки `/i/Ab12cd`
- SQLite база приглашений
- сохранение приглашений
- сохранение ответа получателя
- Telegram-уведомление владельцу
- фото до 5 МБ
- API
- отдельная страница получателя
- простая админская API-выгрузка

## Запуск локально
1. Установить Node.js 18+
2. `npm install`
3. Скопировать `.env.example` в `.env`
4. Заполнить `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `BASE_URL`
5. `npm start`
6. Открыть `http://localhost:3000`

## Telegram
Создай бота через @BotFather, получи токен.
Чтобы узнать chat_id, напиши своему боту сообщение и используй Telegram Bot API getUpdates или любого безопасного бота-информатора.
Никогда не публикуй токен в GitHub.

## Бесплатный деплой
Для простого старта можно использовать Render/Fly.io/Railway или собственный VPS. Важно: SQLite на эфемерном диске может потерять данные после пересоздания контейнера. Для настоящего продакшена лучше заменить SQLite на PostgreSQL/Supabase.

## Важное улучшение перед публичным запуском
Добавить авторизацию админки, rate limiting, CSRF/validation, хранение фото в object storage и PostgreSQL.
